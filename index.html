01

Atlas-Progamador de viagens

O QUE É

O Atlas é uma plataforma de descoberta de destinos que permite explorar lugares, visualizar localizações em mapas interativos, consultar informações meteorológicas e planejar viagens.

COMO FIZ

Desenvolvi o projeto utilizando React e TypeScript, com Tailwind CSS para a interface, React Leaflet para os mapas e integração com a API Open-Meteo para informações meteorológicas. Também utilizei React Router para a navegação entre páginas.

MINHA PARTICIPAÇÃO

Projeto individual, desenvolvido por mim desde a estruturação até a implementação. Fui responsável pela criação das interfaces, funcionalidades, integração com APIs, responsividade e publicação do projeto.

React Tailwind TypeScript Open-Meteo Vite

03

Weatherly — Previsão do Tempo

O QUE É

Dashboard de previsão do tempo em que é possível pesquisar qualquer cidade e ver o clima atual, a previsão por hora e para os próximos 7 dias, com gráfico de temperatura.

COMO FIZ

Construí em React + TypeScript com Vite, consumindo a API real Open-Meteo com respostas tipadas, Recharts para o gráfico de temperatura, pesquisas recentes salvas no localStorage e tratamento de erros (cidade não encontrada, falha da API, sem conexão).

MINHA PARTICIPAÇÃO

Projeto individual, do layout responsivo com tema claro e escuro à integração com a API e ao deploy no GitHub Pages.

React TypeScript Tailwind Recharts
